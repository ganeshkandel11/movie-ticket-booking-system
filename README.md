🎬 **Movie Ticket Booking System** 🍿

The Movie Ticket Booking System is a menu-driven application developed using the C programming language. 💻 It provides a simple and efficient way to manage movie shows and ticket bookings.

🔐 **Admin Panel:** Allows administrators to add, update, delete, and manage movie shows.

🎟️ **Ticket Booking:** Enables users to select movies, choose seats, and book tickets easily.

💺 **Seat Management:** Displays available and booked seats to prevent duplicate bookings.

❌ **Cancel Booking:** Allows users to cancel their tickets when needed.

📋 **Booking History:** Helps users and administrators view ticket and transaction details.

🕒 **Show Schedule:** Displays movie timings and schedules, with a booking cutoff before the show starts.

💾 **File Handling:** Stores movie and ticket information permanently in files.

✨ Overall, this project makes movie ticket booking easier, faster, and more organized while demonstrating the practical use of functions, structures, file handling, and conditional statements in C.
